# 오피스 사용 허가 토큰 연동 (2026-11-25, 오피스 세션에서 작성)

한평생톡 앱에 「오피스 사용 허가 토큰」을 붙인다.

사용자 요청: 오피스에서 토큰을 발급해 직원에게 주고, 앱을 깔면 그 토큰을 넣어 쓰게 한다. 오피스에서 해제하면 앱이 안 켜지게 한다.

## 사용자가 정한 규칙

- **직원 1명 · PC 1대**
  - 토큰은 처음 확인한 PC(`deviceId`)에 묶인다.
  - 다른 PC에서 넣으면 거절한다.
- **해제하면 켜져 있어도 5분 안에 멈춘다**
  - 앱이 켤 때 한 번, 그 뒤 5분마다 확인한다.
  - 해제가 확인되면 발송을 멈춘다. 보내던 사람까지는 마저 보낸다.
  - 그다음 「사용이 해제되었습니다」 잠금 화면을 띄운다.
- **오피스에 연결이 안 될 때** (인터넷 끊김 · 서버 오류)
  - 마지막으로 확인에 성공한 뒤 24시간까지는 그대로 쓴다.
  - 24시간이 넘으면 잠근다.

## 오피스 쪽 확인 주소

- 상태: 로컬에만 있고, 운영 배포는 사용자 지시를 기다리는 중이다.
- `POST {오피스}/api/hanpyeongtok/license`
  - 로그인 없는 공개 주소다. 토큰이 열쇠다.
  - 운영: `https://korhrd-group-db.vercel.app/api/hanpyeongtok/license`
  - 로컬 시험: `http://localhost:3000/api/hanpyeongtok/license`
  - 주소는 환경변수로 바꿀 수 있게 한다.

### 요청 JSON

`{ token, deviceId, deviceName, platform, appVersion }`

- `token`: 「hpt_」로 시작하는 문자열. 관리자가 준 것이다.
- `deviceId`: 이 PC의 고유 번호.
  - 앱이 처음 실행될 때 만들어 앱 데이터 폴더에 저장하고, 계속 같은 값을 쓴다.
  - 값이 바뀌면 다른 PC로 보여 거절된다. 그러면 관리자가 해제한 뒤 새 토큰을 발급해야 한다.
- `deviceName`: `os.hostname()`
- `platform`: `process.platform`
- `appVersion`: `app.getVersion()`

### 응답

- **200** `{ ok: true, userName, checkAfterSec: 300, offlineGraceSec: 86400 }`
  - 사용 가능하다.
  - 다음 확인은 `checkAfterSec` 뒤에 한다.
- **403** `{ ok: false, reason: 'invalid' | 'revoked' | 'device_mismatch' | 'inactive_user', message }`
  - 즉시 잠근다.
  - `message`(한국어)를 그대로 보여 준다.
  - `invalid`면 토큰을 다시 넣는 칸도 같이 보여 준다.
- **그 밖** (500 · 연결 실패 · 시간 초과)
  - 「연결 안 됨」으로 본다.
  - 마지막 성공 뒤 `offlineGraceSec`(24시간) 안이면 계속 쓴다.

### 앱이 지킬 것 (오피스 리뷰에서 나온 것)

- **판정은 상태 코드로만 한다.**
  - 200이면 사용 가능, 403이면 잠근다.
  - 그 밖(400 · 500 · 연결 실패 · 시간 초과)은 모두 「연결 안 됨」으로 본다.
  - `reason`은 403일 때만 본다. 서버 오류 때는 `reason: 'server'`가 올 수도 있다.
- **이 주소는 main 프로세스(또는 앱 안 Next 서버)에서 부른다.**
  - 서버에 CORS 헤더가 없어서, 화면(렌더러)의 `fetch`로 부르면 늘 막힌다.
- **PC 시계를 되돌리는 경우를 막는다.**
  - PC 시계가 마지막 성공 시각보다 앞으로(과거로) 가 있으면 24시간 허용을 쓰지 않고 바로 잠근다.
- **403 `device_mismatch`를 받아도 저장된 토큰을 지우지 않는다.**
  - 잠금 화면에서 「다시 확인」과 「토큰 다시 넣기」를 고르게 한다.
- **새 토큰을 발급하면 같은 직원의 옛 토큰은 자동으로 해제된다.** (직원 1명 · PC 1대)

## 오피스 관리 화면

- 위치: 오피스 관리자 페이지(/admin) 「한평생톡 사용 허가」 탭
- 마스터 관리자가 쓴다.
  - 직원을 골라 토큰을 발급한다. 토큰 원문은 발급할 때 한 번만 보인다.
  - 목록에서 PC 이름과 마지막 확인 시각을 본다.
  - 해제한다.

## 앱에서 할 일 (제안)

1. **첫 실행 · 토큰 없음**
   - 토큰을 넣는 화면(창 하나)을 띄운다.
   - 넣으면 바로 확인하고, 성공해야 대시보드로 간다.
2. **토큰 저장**
   - `safeStorage`로 암호화해 앱 데이터 폴더에 저장한다.
   - 마지막 성공 시각도 저장한다.
3. **켤 때 확인**
   - 실패(403)하면 잠금 화면만 띄운다. Next 서버 · 데몬 발송은 시작하지 않거나 막는다.
   - 연결이 안 되면 24시간 규칙을 따른다.
4. **실행 중 5분마다 확인**
   - 403이면 발송 큐를 멈춘다. 보내던 1명은 마저 보낸다.
   - 그다음 잠금 화면을 띄운다.
5. **잠금 화면**
   - 「토큰 다시 넣기」 버튼과 「다시 확인」 버튼을 둔다.

## 주의

- 앱 코드는 바꿀 수 있어서 완벽한 보안은 아니다. 사내용이라 사용자도 알고 있다.
- 배포(릴리스 · 커밋 push)는 사용자가 「배포해줘」라고 할 때만 한다.
- 오피스 주소가 아직 운영에 없으니 시험은 로컬 오피스(localhost:3000)로 한다.
  - 시험 토큰은 로컬 오피스 /admin 「한평생톡 사용 허가」 탭에서 발급한다.
